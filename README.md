# Portfolio Website

A personal portfolio website built using **HTML and CSS** to showcase my projects, skills, and achievements.  
This portfolio is designed to be responsive and user‑friendly, highlighting my work in web development and design.

## 🚀 Features
- Responsive design using CSS media queries
- Clean and modern layout
- Sections for:
  - About Me
  - Skills
  - Projects
  - Contact Information
- Pure HTML and CSS (no frameworks)
